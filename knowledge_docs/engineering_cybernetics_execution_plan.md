# 工程控制论驱动的交易助手进化执行计划

> 目标：把《工程控制论》的闭环、稳定、抗扰、自适应思想，纳入贵金属个人交易助手的长期进化路线。

## 一句话目标

系统只做三件事：看盘、筛机会、提醒你；交易结果和用户反馈反哺规则，让它慢慢变聪明，但不越过风控边界。

## 当前系统映射

| 控制论概念 | 项目中的对应物 | 当前状态 | 下一步 |
|---|---|---|---|
| 被控对象 | 黄金/白银/外汇市场 | 高噪声、强扰动 | 强化事件/波动场景分类 |
| 传感器 | MT5、宏观事件、外部数据源 | 已接入多源 | 增加延迟和质量评分 |
| 控制器 | 规则引擎、AI、本地模型 | 已分层 | 明确冲突优先级 |
| 执行机构 | 模拟盘/实盘接口 | 模拟为主，实盘需确认 | 继续保持实盘高门槛 |
| 反馈 | 交易结果、提醒效果、用户反馈 | 已开始闭环 | 扩展多窗口效果曲线 |
| 抗扰 | 点差、事件、冷却、日上限 | 已具备 | 增加异常原因透明度 |
| 自适应 | 学习摘要、策略建议、HITL 审批 | 已具备雏形 | 建立周度进化节奏 |

## 第一阶段：观测闭环补强

周期：第 1 周。

任务：

1. 给 AI 判研失败增加结构化原因：未配置、余额不足、模型不存在、权限不足、超时、响应解析失败。
2. 给每条提醒补充“从快照到推送”的延迟字段。
3. 扩展 `alert_effect_outcomes` 到 5m、15m、30m、60m。
4. 学习摘要里增加“提醒太晚率”和“1R 触达率趋势”。

验收：

- 用户看到“AI 离线”时能直接知道原因。
- 每周能知道：哪些提醒有效，哪些提醒太晚，哪些提醒只是噪音。

## 第二阶段：反馈控制补强

周期：第 2 周。

任务：

1. 把用户反馈转成三类轻量控制量：提前提醒、降低噪音、收紧风险。
2. 推送阈值允许自动微调，但开仓阈值只生成待审建议。
3. 建立“推送策略变更前后”的效果对比。
4. 对连续负反馈规则自动降级为 watch 或 frozen。

验收：

- 用户反馈“太晚”后，系统开始提前推 near_zone。
- 用户反馈“噪音”后，低分机会不再刷屏。
- 所有调整都有日志和可回滚依据。

## 第三阶段：抗扰与稳定性

周期：第 3 周。

任务：

1. 增强事件窗口状态机：事件前、事件中、事件后、数据落地后第二段。
2. 强化点差恢复后的即时复评，但不直接开仓。
3. 建立 MT5 数据质量评分：空报价、旧 tick、点差异常、时间偏移。
4. 对模拟盘连续亏损策略族触发冷却或降频建议。

验收：

- 事件窗口内不再把随机波动误当机会。
- 点差恢复后能更快重新检查机会。
- 模拟盘连续亏损时系统主动减速。

## 第四阶段：自适应优化

周期：第 4 周。

任务：

1. 把策略族表现转成参数建议：RR、日上限、冷却、是否只观察。
2. 每条建议必须包含样本数、胜率、净盈亏、最大回撤。
3. 建立“候选参数沙盒”，先回测/模拟，不直接改实盘。
4. 对表现好的规则继续收集样本，不急于放大仓位。

验收：

- 系统能告诉用户“为什么建议收紧某策略”。
- 参数建议只进入人工审批台。

## 第五阶段：控制论化的周度复盘

周期：持续执行。

每周固定检查：

1. 本周提醒有效率、1R 触达率、漏机会原因前三名。
2. 本周模拟盘策略族表现：胜率、净盈亏、回撤、频率。
3. 本周用户反馈：太晚、噪音、风险、无帮助。
4. 本周系统健康：AI 可用性、MT5 数据质量、外部数据源状态。
5. 生成下一周最多 3 个优化动作，避免复杂化。

输出格式：

```text
工程控制论周度进化检查
1. 系统稳定性：
2. 观测质量：
3. 反馈效果：
4. 抗扰能力：
5. 本周只做的 1-3 个优化动作：
```

## 不做清单

1. 不让 AI 直接决定实盘下单。
2. 不因为一两笔盈利就提高仓位。
3. 不因为一次漏机会就大幅放宽规则。
4. 不把复杂模型堆上去掩盖数据质量问题。
5. 不让学习系统绕过人工审批修改实盘配置。

## 自动化触发建议

触发频率：每周一上午执行一次。

自动化任务：

1. 阅读 `knowledge_docs/engineering_cybernetics_evolution_notes.md`。
2. 检查最近 7 天学习摘要、提醒效果、漏机会样本、模拟盘交易结果、用户反馈。
3. 按“稳定性、观测质量、反馈效果、抗扰能力、自适应建议”生成周报。
4. 只提出最多 3 个下周优化动作。
5. 明确哪些动作可自动做，哪些必须人工确认。

执行边界：

- 可以建议和实现推送、报表、诊断、模拟盘学习优化。
- 不可以自动打开实盘交易。
- 不可以自动放宽实盘风控。
- 不可以删除用户数据。
